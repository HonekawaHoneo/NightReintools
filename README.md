# 夜の王チェッカー

ナイトレインの夜の王候補とボス耐性を確認する個人用PWAです。GitHub PagesからSafariで開けます。iPadでGitHubへログインする必要はありません。

## 公開URL

https://honekawahoneo.github.io/NightReintools/

GitHub Pagesを初めて有効にするときは、リポジトリの **Settings > Pages** を開き、Build and deploymentで **Deploy from a branch**、ブランチ **main**、フォルダー **/(root)** を選んで保存します。設定にはリポジトリの管理権限が必要です。mainへ変更を反映すると、サイトも更新されます。

GitHub PagesはHTTPSで配信されます。iPadではSafariで公開URLを開き、**共有 > ホーム画面に追加**を選びます。「Webアプリとして開く」が表示された場合は有効にして追加します。初回読み込み後は、Service Workerがキャッシュしたファイルでオフライン起動できます。

## アプリの使い方

1. 1日目のボスを選びます。
2. 必要に応じて2日目のボスとイベントを選びます。イベントは任意です。
3. 夜の王候補一覧で候補名と簡易耐性値を確認します。
4. 候補、選択したボス、個体や形態を開くと詳細を確認できます。

## セキュリティと公開範囲

このリポジトリとPagesサイトはインターネットから閲覧できます。この個人リポジトリではPagesサイトの閲覧者を限定できません。アプリはブラウザー内で動作する静的ファイルで、サーバー、API、ログイン、解析計測は使いません。閲覧者の通信が自宅のWindows PCを経由することはありません。選択内容はページ内の一時的な状態だけで扱い、外部サービスへ送信・保存しません。

ページにはContent Security Policyを設定し、スクリプト、スタイル、画像、通信、Manifest、Workerを同一サイト内に限定します。アプリは外部スクリプトを読み込まず、画面の文字列をHTMLとして挿入しません。これは同一リポジトリから配信された悪意ある変更までは防げないため、GitHubアカウントを二要素認証またはパスキーで保護し、公開前に変更内容を確認してください。

Windows向けのLAN配信スクリプト、生成証明書、README、設計資料はPagesサイトの配信対象から除外しています。証明書と秘密鍵はGit管理しません。ただし、Pagesから除外したファイルも公開リポジトリのソースからは閲覧できます。LANスクリプトはサイトから実行されません。公開サイトへ配信されるアプリのコードは、リポジトリへの変更で更新されます。

## 収録データ

- 判定対応表は[参考ツール](https://17number.github.io/ern-random-boss-checker/)を参考にしています。
- 耐性値は依頼時に提供された画像から転記しています。
- 正の物理・属性値は弱点、負の値は耐性、0は標準です。
- 状態異常の数値は蓄積耐性値です。割合ではありません。
- 資料にない値は「—」で表示します。
- ゲームの更新に合わせた自動データ更新はありません。
